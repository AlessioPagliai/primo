# primo — start here

For AI agents and for people. primo is an open source humanoid robot by River Family, still in design. This folder is the whole project: with it you can continue the work — mechanics, electronics, purchasing, build, simulation, training.

## Read in this order

1. [README.md](README.md) — what the robot is, numbers, build phases, open points.
2. [docs/handoffs/ai-memory.md](docs/handoffs/ai-memory.md) — the working memory and source of truth: every decision with date, source and open doubts. Newest blocks at the top, superseded blocks are marked. Italian and English mixed. Read the top part fully before changing anything.
3. The files of the area you work on:
   - electronics: [electrical/scheme.md](electrical/scheme.md) — every connection from the battery to each motor, safety chain, CAN buses
   - purchasing: [bom/bom.xlsx](bom/bom.xlsx), [bom/bom.csv](bom/bom.csv) — 108 active rows with supplier, link, price, mass, phase
   - mechanics: [cad/README.md](cad/README.md) — Onshape document, printable STL, first 3MF files
   - simulation: [sim/README.md](sim/README.md), [docs/handoffs/isaac.md](docs/handoffs/isaac.md), [docs/handoffs/mirror-debug.md](docs/handoffs/mirror-debug.md)
   - teleoperation: [docs/handoffs/teleop.md](docs/handoffs/teleop.md)
   - hands, actuators, literature: [docs/hand-design.md](docs/hand-design.md), [docs/actuator-tables.md](docs/actuator-tables.md), [docs/references.md](docs/references.md)

## Rules the project follows

- The BOM is generated: edit `bom/build_bom.py`, never the spreadsheet.
- No hypothesis becomes a BOM row. Unknown items stay at quantity 0 with the missing data listed.
- Never present a guess as a measurement. The ankle crank geometry in `sim/ankle_map.py` is provisional until it is measured in CAD.
- Change a supplier only for a verified equivalent: item, SKU, link and supplier change together.
- Phases are the build order: 1 right arm, right hand, one ankle, battery, safety chain, computer on a bench · 2 legs · 3 the rest.
- Only the right side and the centre are modelled in CAD. The left side is generated by `sim/mirror_urdf.py`.
- Writing stays minimal. Licence CC0.

## State on 2026-09-19

- Nothing is built yet.
- CAD in Onshape, URDF with 30 joints in `sim/urdf/primo.urdf`, printable structure in `cad/stl/`.
- A walking policy is trained in Isaac Lab on rough terrain (run "KneeHard"). The training code is on the simulation workstation and is not in this folder yet: [sim/isaaclab/README.md](sim/isaaclab/README.md).
- Open before ordering: battery shipping and BMS limits, hip yaw motor (RS03 or RS06, decided by simulation), measured ankle crank geometry, whether the e-stop also cuts hand power.
